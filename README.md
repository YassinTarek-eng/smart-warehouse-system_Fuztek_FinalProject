# Smart Warehouse Management System

A modular, object-oriented Smart Warehouse Management System built in C++ using **FLTK (Fast Light Toolkit)** for a lightweight, native graphical user interface. Developed as a collaborative team project.

---

## 🚀 Tech Stack & Environment
* **Language:** C++ (Standard C++17)
* **GUI Framework:** FLTK (Fast Light Toolkit)
* **Compiler / Toolchain:** GCC (MinGW-w64 via MSYS2 UCRT64)
* **Version Control:** Git & GitHub

---

## 📦 Prerequisites for Teammates

To compile and run this project locally, follow these steps to set up your environment:

### 1. Install MSYS2 & FLTK
If you haven't installed MSYS2 yet, download and install it from [msys2.org](https://www.msys2.org/). 

Open your **MSYS2 UCRT64** terminal and install the required compiler and FLTK package:
```bash
pacman -Syu
pacman -S mingw-w64-ucrt-x86_64-toolchain mingw-w64-ucrt-x86_64-fltk
